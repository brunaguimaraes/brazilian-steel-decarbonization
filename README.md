Plant-level decarbonization model of the Brazilian iron and steel industry

Data and code for the paper "Plant-level modelling of deep decarbonization pathways for the Brazilian iron and steel industry", submitted to Energy and Climate Change.
The model is a bottom-up plant-level cost-optimization (MILP) of the Brazilian steel sector from 2023 to 2050, implemented in Python (Pyomo) and solved with HiGHS.

Repository structure
-input/ — input data (plant database, fuel prices, energy intensities, charcoal supply cost curve, and scenario configurations).
-Python code/ — the optimization model.
-resultados/ — model output for each scenario.
